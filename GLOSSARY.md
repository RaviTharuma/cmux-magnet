# Glossary

| Term | Meaning |
|------|---------|
| **cmux-magnet** | cmux plugin for Magnet-style snap zones / equal pane layouts |
| **cmux** | Terminal / agent workspace UI this plugin extends |
| **Magnet** | macOS window manager whose snap-zone UX this plugin echoes |
| **snap zone** | Predefined pane layout region |
